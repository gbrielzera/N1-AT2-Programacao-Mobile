# GamePlay

App de agendamento de partidas em React Native + Expo.

## Requisitos

- Node.js 18+ ([download](https://nodejs.org/))
- npm (vem com Node.js)
- Expo Go ([iOS](https://apps.apple.com/app/expo-go/id982107779) ou [Android](https://play.google.com/store/apps/details?id=host.exp.exponent))

## Instalação

```bash
npm install
```

## Rodar

```bash
npm start
```

Escaneia o QR code com o celular (câmera ou app do Expo Go).

## Builds

```bash
# Preview na web (localhost:8081)
npm run web

# Android (gera APK)
npx expo build:android

# iOS (gera IPA)
npx expo build:ios
```
